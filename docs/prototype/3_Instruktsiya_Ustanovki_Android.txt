ИНСТРУКЦИЯ ПО ЗАПУСКУ И УСТАНОВКЕ ПРИЛОЖЕНИЯ «ЛЕСНОЙ ЧТЕЦ»
==============================================================

В этом архиве находятся два готовых варианта использования приложения:

ВАРИАНТ А: БЫСТРЫЙ ЗАПУСК НА ТЕЛЕФОНЕ МАМЫ ЗА 2 МИНУТЫ (БЕЗ ПРОГРАММИРОВАНИЯ)
----------------------------------------------------------------------------
1. Скопируйте файл `1_Dlya_Mamy_Chistiy_Pleer.html` на смартфон Android (через Telegram, WhatsApp или кабель).
2. Откройте его в браузере Chrome на телефоне — откроется чистый экран с двумя крупными вкладками («▶ СЛУШАТЬ» и «📚 ПИСАТЕЛИ»).
3. Нажмите на меню браузера (три точки в правом верхнем углу) -> «Добавить на главный экран».
4. Чтобы добавить свои MP3-книги, нажмите «⚙️ Вернуть панель родственника» -> «📥 Выбрать MP3/M4B файл...» и выберите аудиофайлы, названные по шаблону:
   Писатель - Год - Название.mp3 (например: Пушкин А.С. - 1836 - Капитанская дочка.mp3).

ВАРИАНТ Б: СБОРКА НАТИВНОГО APK В ANDROID STUDIO (НА БАЗЕ ANDROIDX MEDIA3)
--------------------------------------------------------------------------
В папке `android_studio_project/` лежат готовые исходные файлы:
- `AndroidManifest.xml` — объявление сервиса `ForestAudioService` (foregroundServiceType="mediaPlayback") и `MediaButtonReceiver` для запуска книги кнопкой наушников.
- `build.gradle.kts` — минимальный набор библиотек Media3 (вес APK около 4 МБ, поддержка старых телефонов от Android 7.0 / SDK 24).
- `ForestAudioService.kt` — изолированный плеер ExoPlayer с аппаратной разгрузкой процессора (Audio Offload), кольцевым кэшем SimpleCache на 350 МБ и блокировкой случайных переключений треков от шапки/перчаток на Bluetooth-гарнитуре.
- `ForestSyncWorker.kt` — фоновый планировщик WorkManager для ночной синхронизации семейной папки по домашнему Wi-Fi на зарядке.
