Шаг 5 • Два способа запуска на телефоне

Как установить «Лесной Чтец» на смартфон пожилого человека

Способ А (За 2 минуты без программирования)
  1. Скачайте финальный архив и перешлите файл 1_Dlya_Mamy_Chistiy_Pleer.html на телефон мамы (через Telegram, WhatsApp или по кабелю).
  2. Откройте этот файл в браузере Chrome на телефоне и нажмите в меню (три точки сверху) «Добавить на главный экран».
  3. Положите в папку телефона нужные MP3-книги по шаблону Писатель - Год - Название.mp3 — мама сможет выбирать и слушать их полностью без интернета!
Способ Б (Нативный APK через Android Studio + Media3)
  1. Откройте папку android_studio_project/ из финального архива в бесплатной программе Android Studio.
  2. Внутри уже настроены ForestAudioService.kt (MediaSessionService + Audio Offload + кэш 350 МБ), ForestSyncWorker.kt (ночной Wi-Fi) и MainActivity.kt (Вариант 1 с двумя вкладками).
  3. Нажмите Build → Build APK(s) и установите готовый app-release.apk (весом ~4 МБ) на телефон мамы.

// 1. Фоновый планировщик ночной синхронизации с семейной папкой (Яндекс.Диск WebDAV / Google Drive / JSON)
class ForestSyncWorker(ctx: Context, params: WorkerParameters) : CoroutineWorker(ctx, params) {
    override suspend fun doWork(): Result {
        // Запускается только дома по Wi-Fi (NetworkType.UNMETERED) на зарядке (RequiresCharging)
        // Парсит имена файлов по шаблону: "Писатель - Год - Название.mp3"
        val regex = Regex("""^(.+?)\s*-\s*(1[789]\d{2}|20\d{2})\s*-\s*(.+)\.(mp3|m4b|ogg)$""", RegexOption.IGNORE_CASE)
        return Result.success()
    }
}

// 2. Изолированный аудиосервис Media3 с защитой кнопок гарнитуры и кэшем 350 МБ

    override fun onCreate() {
        super.onCreate()
        val evictor = LeastRecentlyUsedCacheEvictor(350L * 1024L * 1024L)
        val simpleCache = SimpleCache(File(cacheDir, "audiobooks"), evictor, StandaloneDatabaseProvider(this))

}
