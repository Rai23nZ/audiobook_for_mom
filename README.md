# Вслух

Android-приложение для прослушивания аудиокниг и стихов. Сделано для пожилого человека,
который слушает книги на прогулке в лесу. На экране всего две вкладки:
**▶ СЛУШАТЬ** (текущая книга) и **📚 ПИСАТЕЛИ** (все книги по писателям и годам).
Настроек в приложении нет.

## Установка

1. Откройте страницу **Releases** этого репозитория и скачайте последний `Vslukh-*.apk`
   (APK собирается автоматически, см. `.github/workflows/build-apk.yml`).
2. Откройте файл на телефоне. Android попросит разрешить установку из этого источника — разрешите.
3. Обновления ставятся поверх, позиции книг сохраняются.

Нужен Android 7.0 или новее.

## Откуда берутся книги

* **Семейная папка Google Drive** «КнигиДляМамы» вшита в приложение и в нём не меняется.
  Чтобы дать маме новую книгу, положите файлы в эту папку. Список книг обновляется по Wi-Fi
  при запуске приложения, раз в 6 часов и по кнопке **«🔄 Синхронизировать сейчас»** на вкладке
  «Писатели». Если Wi-Fi не подключён, приложение попросит подключиться.
* **🎁 Бесплатные книги (LibriVox)** — каталог русской классики в общественном достоянии (~76 записей).

**Книги сами в телефон не скачиваются**, чтобы не занимать память. Новая книга видна в списке
с пометкой «📥 Нажмите, чтобы скачать» и загружается по нажатию, только по Wi-Fi.
Файлы, убранные из папки Drive, удаляются и с телефона.

Папки и файлы в Google Drive должны быть видны по ссылке («Все, у кого есть ссылка»).
Если у вложенной папки или файлов доступ ограничен, приложение их не увидит.

### Прослушанные книги

Дослушанная до конца книга получает метку **✓ ПРОСЛУШАНО** и остаётся в списке.
**На следующий день** её файлы удаляются из телефона. Чтобы послушать её снова,
нажмите на неё: книга скачается заново.

### Как называть файлы в папке Google Drive

* Один файл: `Пушкин А.С. - 1836 - Капитанская дочка.mp3`
* Книга из нескольких файлов — папка `Толстой Л.Н. - 1869 - Война и мир/` с файлами `01.mp3`, `02.mp3`, …
* Или папка писателя: `Есенин С.А./1924 - Письмо матери.mp3`

Форматы: MP3, M4A, M4B, OGG, OPUS, AAC, FLAC, WAV.

## Что умеет плеер

* Читает в фоне с погашенным экраном, показывает крупные кнопки в шторке и на экране блокировки.
* Запоминает место остановки каждой книги (и главу в многофайловой книге).
* Когда книга заканчивается, сам переходит к следующему непрослушанному произведению
  того же писателя по годам. Удобно для стихов: они идут одно за другим.
* **Защита наушников:** кнопка гарнитуры только ставит на паузу и продолжает чтение. Двойное
  нажатие не переключит главу и не начнёт книгу заново.
* Если приложение закрыто, нажатие кнопки на наушниках продолжает последнюю книгу.
* Ставит чтение на паузу на время телефонного звонка и при отключении наушников.

## Для разработчика

Kotlin, Jetpack Compose, AndroidX Media3 (ExoPlayer + `MediaSessionService`), WorkManager.

```
app/src/main/java/ru/lesnoychtets/app/
  data/       разбор имён файлов, библиотека, память позиций, Google Drive, каталог LibriVox
  playback/   PlaybackService (Media3) и очередь воспроизведения
  sync/       фоновые задачи: список книг Drive, скачивание книг по кнопке, удаление прослушанного
  ui/         экраны Compose
```

Папка Drive задана константой `GoogleDriveFolder.FAMILY_FOLDER_ID`. Список её файлов
приложение получает со встраиваемой страницы папки (`embeddedfolderview`), без API-ключей.

Идентификатор пакета остался прежним (`ru.lesnoychtets.app`), чтобы «Вслух» ставился
поверх уже установленной версии.

Локальная сборка (нужен Android SDK, `sdk.dir` в `local.properties`):

```
./gradlew testReleaseUnitTest assembleRelease
```

APK подписывается ключом `keystore/release.jks`. Ключ хранится в репозитории, поэтому CI
собирает каждую версию с одной и той же подписью и обновления ставятся поверх. Репозиторий
публичный, так что подписать APK этим ключом может любой. Чтобы перейти на закрытый ключ,
добавьте в секреты репозитория `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
После смены ключа приложение придётся один раз удалить и установить заново.

Исходный макет и материалы, по которым сделано приложение, лежат в `docs/prototype/`.
