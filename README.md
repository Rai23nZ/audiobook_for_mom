# Лесной Чтец

Android-приложение для прослушивания аудиокниг и стихов. Сделано для пожилого человека,
который слушает книги на прогулке в лесу. На главном экране всего две вкладки:
**▶ СЛУШАТЬ** и **📚 ПИСАТЕЛИ**. Книги разложены по писателям и годам, приложение
помнит место остановки каждой книги и работает без интернета.

## Установка

1. Откройте страницу **Releases** этого репозитория и скачайте последний `LesnoyChtets-*.apk`
   (APK собирается автоматически, см. `.github/workflows/build-apk.yml`).
2. Откройте файл на телефоне. Android попросит разрешить установку из этого источника — разрешите.
3. Обновления ставятся поверх, позиции книг сохраняются.

Нужен Android 7.0 или новее.

## Откуда берутся книги

Настройки для родственников открываются внизу вкладки «Писатели»: кнопку
**«⚙ Настройки для родственников»** нужно **удерживать**. Это сделано, чтобы мама не попала туда случайно.

| Источник | Как работает |
|---|---|
| **Папка на телефоне** | Скопируйте MP3 в любую папку (кабелем, из Telegram) и один раз выберите её в настройках. |
| **Google Drive** | Создайте папку, откройте доступ «Все, у кого есть ссылка», вставьте ссылку в настройках. Приложение раз в 6 часов (по умолчанию только по Wi-Fi) скачивает новые файлы и удаляет те, что убрали из папки. Кнопка «Скачать сейчас» запускает синхронизацию сразу. |
| **🎁 Бесплатные книги (LibriVox)** | Каталог русской классики в общественном достоянии: Пушкин, Толстой, Тургенев, Гончаров, Чехов, Ахматова, Гумилёв, Мандельштам, Северянин и др. (~76 записей). Книга скачивается в телефон одной кнопкой и дальше слушается без интернета. |

Ещё в каталоге есть ссылки на другие легальные бесплатные библиотеки: «Свет» (РГБ) и
«ЛитРес: Библиотека». Это отдельные приложения, книги из них слушаются там же.

### Как называть файлы

* Один файл: `Пушкин А.С. - 1836 - Капитанская дочка.mp3`
* Книга из нескольких файлов — папка `Толстой Л.Н. - 1869 - Война и мир/` с файлами `01.mp3`, `02.mp3`, …
* Или папка писателя: `Есенин С.А./1924 - Письмо матери.mp3`

Форматы: MP3, M4A, M4B, OGG, OPUS, AAC, FLAC, WAV.

## Что умеет плеер

* Читает в фоне с погашенным экраном, показывает крупные кнопки в шторке и на экране блокировки.
* Запоминает место остановки каждой книги (и главу в многофайловой книге).
* Когда книга заканчивается, сам переходит к следующему произведению того же писателя по годам.
  Удобно для стихов: они идут одно за другим.
* **Защита наушников:** кнопка гарнитуры только ставит на паузу и продолжает чтение. Двойное нажатие
  (случайное касание шапкой или воротником) не переключит главу и не начнёт книгу заново.
* Если приложение закрыто, нажатие кнопки на наушниках продолжает последнюю книгу.
* Ставит чтение на паузу на время телефонного звонка и при отключении наушников.

## Для разработчика

Kotlin, Jetpack Compose, AndroidX Media3 (ExoPlayer + `MediaSessionService`), WorkManager.

```
app/src/main/java/ru/lesnoychtets/app/
  data/       разбор имён файлов, библиотека, память позиций, Google Drive, каталог LibriVox
  playback/   PlaybackService (Media3) и очередь воспроизведения
  sync/       фоновые задачи: синхронизация Drive, скачивание книг LibriVox
  ui/         экраны Compose
```

Локальная сборка (нужен Android SDK, `sdk.dir` в `local.properties`):

```
./gradlew testReleaseUnitTest assembleRelease
```

APK подписывается ключом `keystore/release.jks`. Ключ хранится в репозитории, поэтому CI
собирает каждую версию с одной и той же подписью и обновления ставятся поверх. Репозиторий
публичный, так что подписать APK этим ключом может любой. Чтобы перейти на закрытый ключ,
добавьте в секреты репозитория `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
После смены ключа приложение придётся один раз удалить и установить заново.

Исходный кликабельный макет и материалы, по которым сделано приложение, лежат в `docs/prototype/`.
